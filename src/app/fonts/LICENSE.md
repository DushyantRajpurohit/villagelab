# Bundled fonts

**Archivo** — Copyright 2020 The Archivo Project Authors
(<https://github.com/Omnibus-Type/Archivo>). Licensed under the SIL Open Font
License 1.1. <https://openfontlicense.org/>

One variable file (latin subset, weight 100–900, width 62–125) carries the whole
site: condensed and heavy for headlines and squad numerals, normal width for
text, a notch narrower with tabular figures in tables. Self-hosted rather than
fetched from a CDN so the build has no network dependency and no third party
sees a visitor's IP.

No Supercell font is used. Supercell's own typeface is proprietary.
