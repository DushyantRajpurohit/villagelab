# Bundled fonts

**Baloo 2** — Copyright (c) Ek Type. Licensed under the SIL Open Font License 1.1.
<https://openfontlicense.org/> · <https://fonts.google.com/specimen/Baloo+2>

Used for display headings only. Self-hosted (latin subset) rather than fetched
from Google's CDN so the build has no network dependency and no third party sees
a visitor's IP.

No Supercell font is used. Supercell's own typeface is proprietary; this is an
independently licensed face chosen for a similar weight and roundness.
